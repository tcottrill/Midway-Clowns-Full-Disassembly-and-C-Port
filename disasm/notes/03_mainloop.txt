; $0A41-$0DF3  game start, main loop, balloons, serve, score line, playfield, autopilot, row bonus

## 0A41 SECTION 4  Main loop and its tasks ($0A41-$0DF3)
   The foreground: a small script interpreter that sequences attract mode and
   the game, and - whenever the script waits - one pass over the game tasks.
   The tasks only change variables and draw text; the interrupts draw the
   moving objects.

== 0A41 GameStart - Normal power-on: clear all RAM and start the script at AttractScript.
0A41 Tone and sounds off
0A48 A = 0: all 256 blocks, $2000-$3FFF
0A4B Script starts with attract mode

== 0A51 MainLoop - Run script commands until a WAIT, then one pass of the game tasks.
   The script byte at SCRIPT_PTR is an even opcode 2-$20 that indexes
   ScriptOps; the handler gets the address of its arguments in DE and returns
   here (this routine's address is pushed first). Opcode 0 is WAIT: the pointer
   stays on it and the tasks below run every pass until a timer event moves the
   script on (ScriptTimerDone, CheckTimeout). Interrupts are off while commands
   run and back on at a WAIT.
0A51 Every path returns to MainLoop
0A5A Script opcode
0A5C 0 = WAIT: run the game tasks
0A5F No interrupts while the script changes things
0A61 Step past the opcode
0A64 DE -> arguments
op 0A65 ScriptOps-2
0A65 Opcodes start at 2
0A6B + opcode
0A70 To the handler
^0A71 WAIT: one pass of the game tasks
0A72 Act on what the flyer touched
0A75 Scores to text, one character to the screen
0A78 Expired timers
0A7E Script timeout
0A81 New jump wanted?
0A84 Flyer picture and erase mode
0A87 Another score character
0A8A Contact again: it must not wait a whole pass
0A8D Another score character
0A93 Floor and ledges
0A96 Attract mode steers the seesaw
0A99 Game on?
0A9D No
0AA1 A balloon row emptied?
0AA4 Back to MainLoop

== 0AA5 Random - Next 8-bit pseudo-random number in A (and RNG_SEED).
   Shift register: the seed moves right one bit and the parity of its bits 0, 2,
   3 and 4 comes in at the top. A zero seed is replaced by $FF first.
0AAC Seed 0 would stay 0
0AB1 Taps: bits 0, 2, 3, 4
0AB3 Even parity: shift in 0
0AB6 Odd: shift in 1
0AB9 Seed >> 1
0ABD New seed

== 0ABF BalloonTasks - The six odd-frame balloon passes: first balloon, routine.
   A pass moves every other balloon of one row by one pixel, so each balloon
   moves once in 12 frames. Top and bottom rows drift right, the middle row left.

== 0AD7 AnimateFlyer - Choose the flyer's picture and erase mode from its height.
   Not while it is being served. Y $B0-$BB (coming down on the seesaw): stand
   upright, blank-box erase. Above $B0: erase by restoring the background, and
   from $54 down tumble through pictures 1-3, one step every 7 ticks. In the
   balloon rows (above $54) the picture is left alone.
0AD7 Walking on its ledge?
0ADC The flyer
0AE1 Not in use
0AE2 DE = the object
op 0AE4 CL_Y
0AE8 Its Y
0AE9 Down at the seesaw already
0AEC Just above the seesaw?
0AEE No: higher up
0AF1 Erase by blanking the box
0AF6 CL_FRAME
0AF8 Picture 0: standing
0AFA In the balloon rows?
0AFC Higher than the seesaw: erase by restoring the background
0B01 Yes: keep the picture
0B02 Time for the next tumble picture?
0B08 Every 7 ticks
0B0A CL_FRAME
0B0D Pictures 1, 2, 3, 1 ...

== 0B6D PlayerRow - HL = balloon address DE, moved to player 2's rows when PLAYER is 2. DE = P2_OFFSET.

== 0B78 DrawBalloon - Draw the 8-row balloon picture DE at screen address HL through the shifter.

== 0BA4 ServeClown - Start a new jump when SERVE_REQUEST is set.
   One clown object becomes the rider, standing on the seesaw at Y $C4. The
   other becomes the flyer and starts on one of the four ledges, picked at
   random from ServeTable: it walks (slow object) toward the middle until
   TMR_SERVE_JUMP makes it jump off one second later.
0BA7 Requested?

0BAF 1-4

0BB5 6 bytes per entry

0BCC HL = rider object, DE = flyer object
0BCD Rider: in use
0BD0 -> CL_Y
0BD2 Standing on the seesaw
0BD9 HL -> past the flyer's first six bytes
0BDB Copy the entry backwards:
0BDE Y, YVEL, X, XVEL, FRAME, STATE
0BE6 Walk animation starts
0BEB No gravity or tumbling yet
0BEE Jump off after 30 ticks

== 0BF4 ServeTable - Flyer start values for the four ledges: CL_Y down to CL_STATE.

0C1D as a digit

== 0C25 DrawNextDigit - In a game: draw the next character of TEXT_BUF at its place on the score line.
   One character per call (three calls per main loop pass). Six characters in a
   one-player game, eleven with two players.
0C29 Attract mode
0C2E Player 1 score and jumps left
0C33 Two players: the second score as well
0C3A Past the last one?
0C3E Start again
0C43 Screen address of this character
0C4B HL -> the character
0C4F One character

== 0C54 BcdToChars - Write the BCD byte at BC as two digit characters at HL.
0C55 High digit
0C5C Low digit

== 0C62 FormatScore - Write the 2-byte BCD score at BC as 5 characters at HL.
   Four digits with leading zeros turned into blanks ('@'), then the fixed
   final '0': scores count tens of points.
0C62 DE = start of the text
0C6A From the start:
0C6B blank the leading zeros
0C6F The units digit is always 0

== 0C73 HighNibbleToChar - A = character for the high nibble of A.

== 0CE5 Autopilot - Attract mode: put the seesaw under the falling clown.
   PADDLE_POS = flyer X - 4 when the right end is down, X - 24 when the left
   end is down, so that the flyer comes down on the raised end. If that is
   not within 0-$DF, the seesaw goes to the end of the floor on the flyer's
   half of the screen.
0CE9 Only in attract mode
0CEA Just launched: leave the seesaw
0CF4 Flyer not in use
0CF5 HL -> CL_X
0CF8 B = X

0D03 Left end: 24 left of the flyer
0D06 Within 0-$DF?
0D08 Yes
0D0B Flyer in the right half?
0D0C Yes: far right
0D11 No: far left

== 0D16 CheckRowsCleared - In a game: award the bonus when the player empties a balloon row.

   are refilled. Either way BONUS and the value are shown, the bonus tune
   plays and flyer and balloons freeze for 3 seconds.
